# FeatherView 路线图

## 已完成（v0.1.x）

- [x] Windows 文件关联（md/txt/log/json/yaml/toml，v0.1.1）
- [x] 单实例文件打开（v0.1.1）
- [x] 阅读位置记忆与恢复（v0.1.1）
- [x] 启动参数规范化（中文/空格/多参数，v0.1.1）
- [x] 窗口标题同步、拖拽提示、加载防护（v0.1.1）

## P1：完善 MVP（当前优先级最高）

- [ ] PDF 阅读（渲染器接口已预留，动态加载 PDF.js，不阻塞首屏）
- [ ] 大文件分块读取与虚拟滚动（解除 10MB 文本上限）
- [ ] 阅读位置记录 / 文档收藏
- [ ] CSV 表格阅读
- [ ] 更多代码语言高亮与主题

## P2：多格式扩展

- [ ] DOCX 快速预览（只读文本提取）
- [ ] EPUB 阅读（章节化阅读、进度记忆）
- [ ] Markdown 编辑模式（只读/编辑切换）
- [ ] 导出 HTML 或 PDF
- [ ] 多标签页
- [ ] 文件夹浏览与最近目录
- [ ] .mdpack 文档包（打包 Markdown + 资源）

## P3：移动端体验

- [ ] Android 构建与发布（`content://` 打开、分享入口）
- [ ] iOS 构建与发布（文件 App 导入、分享扩展）
- [ ] 移动端手势（滑动翻页、双击缩放）
- [ ] iCloud / 系统文件提供器适配

## P4：编辑和高级能力

- [ ] Markdown 所见即所得编辑
- [ ] 全文检索（当前目录）
- [ ] 插件系统（渲染器 / 命令扩展）

- [ ] 阅读统计与数据导出
- [ ] 自动更新系统

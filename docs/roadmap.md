# FeatherView 路线图

## P1：完善 MVP（当前优先级最高）

- [ ] PDF 阅读（渲染器接口已预留，动态加载 PDF.js，不阻塞首屏）
- [ ] 大文件分块读取与虚拟滚动（解除 10MB 文本上限）
- [ ] 文件关联安装配置（Windows 右键"打开方式"、双击打开）
- [ ] 阅读位置记录（关闭后恢复上次位置）
- [ ] 文档收藏 / 置顶
- [ ] CSV 表格阅读
- [ ] 更多代码语言高亮与主题

## P2：多格式扩展

- [ ] DOCX 快速预览（只读文本提取）
- [ ] EPUB 阅读（章节化阅读、进度记忆）
- [ ] Markdown 编辑模式（只读/编辑切换）
- [ ] 导出 HTML 或 PDF
- [ ] 多标签页
- [ ] 文件夹浏览与最近目录
- [ ] .mdpack 文档包（打包 Markdown + 资源）

- [ ] Android 构建与发布（`content://` 打开、分享入口）

- [ ] 移动端手势（滑动翻页、双击缩放）
- [ ] iCloud / 系统文件提供器适配

- [ ] Markdown 所见即所得编辑
- [ ] 全文检索（当前目录）

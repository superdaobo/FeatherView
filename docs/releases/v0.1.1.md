# FeatherView v0.1.1 Release Notes

## 版本概述

v0.1.1 是 Windows 实用性与可靠性更新，聚焦「真正融入 Windows 日常文件打开流程」与「回到上次阅读位置」。

## 新增功能

### Windows 文件关联

安装后，以下格式可通过「打开方式」选择 FeatherView，或直接双击打开：

```
.md  .markdown  .mdown  .txt  .log  .json  .yaml  .yml  .toml
```

- 不强制替换任何默认应用（由用户选择）
- 卸载时由安装器自动清理关联
- 中文路径、带空格路径、多段扩展名均可正常打开

### 单实例文件打开

- 应用已运行时，再次双击关联文件不会创建第二个实例
- 现有主窗口自动恢复、解除最小化并聚焦
- 新文件通过统一入口（`documentStore.open`）打开

### 阅读位置记忆

- 支持 Markdown / TXT / LOG / 代码 / JSON
- 重新打开文档自动回到上次阅读位置（标题锚点优先，其次相对比例）
- 滚动防抖 500ms 保存，窗口关闭前最终保存
- 最多保存 150 条，自动淘汰最旧
- 可在设置中关闭，或一键清除全部记录

## 改进

- 拖拽提示覆盖层：「松开以使用 FeatherView 打开」；拖入文件夹给出明确提示
- 窗口标题随文档同步：`文件名 — FeatherView`；返回首页恢复默认标题
- 打开文件期间按钮禁用，防止重复读取
- 多文件打开（启动参数/拖拽/第二实例）只打开第一个并提示一次

## 修复

- 重复文件打开事件
- 最近文件重复记录
- 启动参数边界情况（Flag、不存在路径、URL、文件夹、空参数）
- 渲染器容器晚于挂载时的滚动监听丢失

## 支持的关联格式

| 扩展名 | 说明 |
| --- | --- |
| md / markdown / mdown | Markdown 文档 |
| txt / log | 纯文本 / 日志 |
| json | JSON 数据 |
| yaml / yml | YAML 配置 |
| toml | TOML 配置 |

（有意不关联图片、代码与系统文件，避免抢占用户已有编辑器。）

## 升级说明

- 直接覆盖安装 v0.1.1 安装包即可，设置与最近文件保留
- 阅读位置为新增功能，无需迁移

## 已知限制

- 文件关联为 Windows 专属（安装器注册）
- 一次只打开一个文件（多标签在后续版本）
- 阅读位置不记忆图片缩放/平移状态
- 单实例由 `tauri-plugin-single-instance` 实现，Linux/macOS 同样生效（本版本仅发布 Windows 安装包）

- 可执行文件：`FeatherView_0.1.1_x64.exe`

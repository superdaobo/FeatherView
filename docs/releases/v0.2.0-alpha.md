# 览匣 FeatherView v0.2.0-alpha.1（Nightly）

> Alpha 版本：功能可用但未全面实机验证，仅用于开发与测试。

## 版本概述

v0.2.0-alpha.1 将览匣从单文件阅读器升级为本地文件工具箱方向的第一步：
大文件读取、多标签、虚拟滚动、CSV/PDF/压缩包预览、收藏、品牌更名「览匣」。

## 新增功能

- **品牌**：用户可见名称统一为「览匣 FeatherView」（窗口标题、首页、设置、错误页、README）
- **大文件**：Rust 范围读取会话（open_read_session / read_range / close_read_session），UTF-8/UTF-16 分块边界对齐、文件变化检测、10MB 上限解除
- **多标签页**：最多 16 个标签、同文件去重激活、切换不重读（快照缓存）、阅读位置按标签记忆
- **虚拟滚动**：文本/日志超过 5 万行启用（固定行高 + 可视窗口），保留行号与搜索
- **CSV 阅读器**：分隔符自动检测、引号/换行字段、表头、大表截断提示
- **PDF 阅读器**（懒加载）：翻页、缩放、加载/错误/密码提示；pdfjs-dist 独立 chunk 不进首屏
- **压缩包内容列表**：ZIP/TAR/GZ 条目展示（Rust 解析后续版本）
- **收藏**：星标收藏、首页收藏区、上限 100
- **文件夹入口**：首页「打开文件夹」（浏览能力随 Rust list_dir 就绪自动生效）
- **Agent Test Mode**：`--agent-mode` 本地 HTTP 调试接口（127.0.0.1 + Token，仅开发构建）
- **Android/iOS 适配**：content:// 与 file:// 读取命令、Kotlin 桥接、Info.plist 配置、CI 构建 job

## 改进

- 首页/阅读页品牌文案统一
- 大文件打开从"报错"变为"骨架 + 会话读取"
- 状态栏行数/字数支持会话模式（stats 事件）

## 修复

- 虚拟滚动触发条件与字符阈值互斥的问题
- 大文件服务前端上限防护（200MB 循环防护）

## 已知限制

- PDF 渲染需 WebView2 实机验证；大 PDF 主线程渲染可能卡顿
- Android/iOS 构建产物未在实体设备验证
- Windows Preview Handler：源码就绪，COM 编译适配进行中（见 docs/architecture/windows-preview-handler.md）
- 大文件会话为"顺序读完"而非按需分页
- 未签名 iOS 产物不可直接安装
